## 智慧分流規則（BotEngine.decide）

1. 兩個以上型號 → 只用「A 和 B 比較」FAQ（由資料表算出差異），沒有就交給 Agent
2. 一次問好幾項（「沙塵、凍融、艦載振動」）→ Agent 逐項查
3. 指向上一則的說法（「第 13 項」）→ Agent（看得到對話）
4. 其他 → FAQ；「有哪些型號／有哪些項目」這類清單題標 `#通用`、降低優先，具體測試或型號的題目先命中
5. FAQ 沒命中 → Agent

結論：Agent 擅長理解問題與上下文，資料算好的 FAQ 在比較與清單題 100% 精準，兩者分工比單用任一種好。
